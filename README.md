# Інформаційна система логістики гуманітарної допомоги

Веб-застосунок для обліку складів, вантажів, заявок на допомогу та прогнозування попиту на ресурси.

**Технології:** Java 17, Spring Boot 3, React (Vite), PostgreSQL.

**Репозиторій:** https://github.com/kirilkireev03-ops/humanitarian-logistics

## Структура проєкту

| Каталог | Опис |
|---------|------|
| `backend/` | REST API (Spring Boot, JPA, JWT) |
| `frontend/` | Клієнтська частина (React, MUI) |
| `docs/` | ER-діаграма бази даних |
| `scripts/` | Допоміжні SQL-скрипти |

## Запуск

**1. База даних**

```bash
docker compose up -d
```

Створюється PostgreSQL: база `logistics`, користувач/пароль `logistics` / `logistics`.

Без Docker — виконати `scripts/init-postgres-logistics.sql` від імені `postgres`.

**2. Backend**

```bash
cd backend
mvn spring-boot:run
```

REST API працює на порту **8080**.  
Інтерактивна документація Swagger UI — шлях `/swagger-ui.html`.

**3. Frontend** (окремий термінал)

```bash
cd frontend
npm install
npm run dev
```

Клієнтська частина працює на порту **4185**.

## Демо-облікові записи

| Логін | Пароль | Роль |
|-------|--------|------|
| admin | admin123 | адміністратор |
| coordinator | coord123 | координатор |

На порожній базі при старті backend автоматично завантажуються тестові склади, вантажі та транзакції.

## Основні можливості

- довідники складів і вантажів;
- облік залишків і руху (надходження, відпуск, переміщення);
- заявки на допомогу зі зміною статусу;
- панель показників і журнал дій користувачів;
- прогноз попиту за історією відпусків (SES, метод Холта, ковзне середнє).
